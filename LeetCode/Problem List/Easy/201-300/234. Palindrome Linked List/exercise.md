Given the `head` of a singly linked list, return `true` if it is a _palindrome_ or `false` _otherwise_.


#### **Example 1:**
```
![pal1linked-list](images/pal1linked-list.jpg)
Input: head = [1,2,2,1]
Output: true
```

#### **Example 2:**
```
![pal2linked-list](images/pal2linked-list.jpg)
Input: head = [1,2]
Output: false
```
 

#### **Constraints:**

* The number of nodes in the list is in the range `[1, 10^5]`.
* `0 <= Node.val <= 9`
